Work with arrays, hashes and Enumerable

Transform a collection while keeping track of the returned value.

Learn

An Array stores ordered values and uses zero-based indexes. A Hash associates keys with values. The colon form ruby: 10 creates a Symbol key, so fetch(:ruby) retrieves it.

Enumerable methods describe common operations: map builds transformed values, select keeps matching values, and reduce combines values into an accumulator. These are APIs, not special language syntax. They use the blocks introduced in the iteration lesson.

Example output
[2, 4, 6, 8]
[2, 4]
10
10
0

Experiment

Change even? to odd? and use 10 instead of 0 as the initial reduce value.

Answer

select returns [1, 3]. reduce returns 20 because it starts with 10 and then adds all four numbers.
