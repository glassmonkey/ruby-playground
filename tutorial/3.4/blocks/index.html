Yield to blocks and store callable behavior

Pass behavior to a method and call a Proc or lambda.

This lesson uses the implicit it block parameter, introduced in Ruby 3.4.

Learn

A block is behavior supplied alongside a method call. A method can invoke it with yield. Block parameters receive the values passed by yield. Blocks can use local variables from their surrounding scope.

A Proc or lambda makes callable behavior available as an object. Invoke it with call. Lambdas enforce argument counts more like methods; Proc and lambda also differ in how return behaves. This example stays with simple expression bodies.

Ruby 3.4 introduced it as an implicit block parameter. In the final expression, it refers to each array element. Use an explicit parameter such as |number| when a descriptive name makes the code easier to follow.

Answers

Trace the yielded value

The method yields 5 here instead of 2, so the block result changes from 6 to 15. The Proc and lambda still receive 4, so their results stay 8 and 12.

Yield a value

The block receives Matz and returns the interpolated string Hello, Matz.

Call stored behavior

The lambda runs its block body with the argument and returns BLOCKS.

def twice
  yield 2
end
p twice { |n| n * 3 }
double = Proc.new { |n| n * 2 }
triple = ->(n) { n * 3 }
p double.call(4)
p triple.call(4)
p [1, 2, 3].map { it * 2 }
