Lesson 9 of 16 · Ruby 3.4

Create objects with classes

Initialize instance state and expose behavior through methods.

Learn

A class defines behavior for its instances. new creates an instance and calls initialize. Instance variables belong to an object, so separate instances can hold different values.

attr_reader defines a reader method. Public methods form the callable interface; private methods support its implementation. Inheritance lets a subclass reuse and specialize behavior, and super invokes the corresponding superclass implementation.

Experiment

  1. Compare instance values

    Compare this run with Example: why is first.value 3 here, while second.value stays 10?

  2. Keep state per object

    Create another Lamp with "red" and print its color.

  3. Update instance state

    Call increment two more times before printing. What is value?

Answers

Compare instance values

This run increments first three times, so its value is 3; Example increments it once, so it is 1. second is a separate object and remains 10 in both runs.

Keep state per object

Each new instance receives its own @color value, so the second lamp reports red.

Update instance state

Each call adds one to this counter object, so value becomes 3.

class Counter
  attr_reader :value
  def initialize(start = 0)
    @value = start
  end
  def increment
    @value += 1
  end
end
first = Counter.new
second = Counter.new(10)
first.increment
p first.value
p second.value
