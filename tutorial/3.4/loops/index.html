Repeat work and control a loop

Use iteration, next and break without creating an unbounded loop.

Learn

Iteration repeats work for each value. each yields successive values to a block, while while repeats as long as its condition stays truthy. until repeats while its condition is falsey.

next skips the remainder of the current iteration. break leaves the loop. A loop that never changes its condition can run forever; this playground imposes an execution timeout, and its Stop control can cancel a run.

Example output
1
3
4
2

Experiment

Move break if number == 5 before next, then change the break value to 3.

Check your understanding

The iteration prints only 1. The value 2 is skipped and the loop ends before printing 3. The final count is still 2.

A useful tip

A .. range includes its end; a ... range excludes it. That can change how many times an iteration runs.

Explore the official manual

  • Official Ruby 3.4 documentation: Control Expressions
(1..5).each do |number|
  next if number == 2
  break if number == 5
  puts number
end
count = 0
while count < 2
  count += 1
end
p count
