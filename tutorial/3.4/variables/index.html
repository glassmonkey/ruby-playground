Assignment and object references

Use local variables and understand when two names refer to the same object.

Run it first

Run the example and see what it prints. Each run starts fresh.

Expected output of the original example (Ruby 3.4)
Ruby!
Ruby!
Python

How it works

Assignment associates a name with a value. Reassigning a variable changes what that name refers to. It does not automatically copy an object. This distinction matters when an object can be modified.

Local variable names usually begin with a lowercase letter. Constants begin with an uppercase letter; instance variables begin with @ and will appear in the classes lesson. A method has its own local-variable scope.

Try it yourself

Change other = name to other = name.dup. What does the first puts print?

Check your understanding

It prints Ruby. dup creates a separate string, so appending to other no longer changes name.

Watch out for

Assignment is not a deep copy. A copy of a collection can still contain references to the same nested objects.
