Scope a method extension with refinements

Activate an extension in a lexical scope.

Learn

Reopening a class changes methods for its users broadly. A refinement can limit where an extension is active. Define the extension inside refine, then activate the containing module with using.

Activation follows where code is defined, not simply which object is passed around. A method defined outside the active scope does not gain the refinement merely because a caller activated it. Keep this distinction in mind when splitting code into methods.

Example output
Ruby!

Experiment

Replace self + "!" with upcase + "!".

Answer

The output becomes RUBY!: the refined method calls the existing upcase method and appends punctuation.

Explore the official manual

  • Official Ruby 3.4 documentation: Refinements
module ExcitedText
  refine String do
    def excited
      self + "!"
    end
  end
end
using ExcitedText
puts "Ruby".excited
