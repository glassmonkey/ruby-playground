Define methods and pass arguments

Define a reusable method with a positional and keyword argument.

Before you start: Work with arrays, hashes and Enumerable. Examples use bundled Ruby 4.0.

Understand the idea

A method packages a calculation behind a name. Define it with def and close the body with end. Ruby returns the last evaluated expression unless an explicit return exits the method earlier.

Positional arguments are matched by position. Keyword arguments are passed by name. Defaults let callers omit an argument. Parentheses at the call site make the argument list clear even when Ruby permits omitting them.

Read, predict, then run

Predict what this program will print before opening it in the playground.

def greeting(name, punctuation: "!")
  "Hello, #{name}#{punctuation}"
end
puts greeting("Ruby")
puts greeting("Matz", punctuation: "?")

Expected output

Hello, Ruby!
Hello, Matz?

Try it yourself

Change the default punctuation to ".". Which call changes?

Check your understanding

Only greeting("Ruby") changes. The second call explicitly supplies its own keyword value.

Watch out for

Printing inside a method is different from returning a string. A method ending in puts returns nil.
