Handle an expected failure

Raise an exception, handle a specific error and run cleanup.

Development course: behavior may change with future runtime updates.

Learn

An exception interrupts normal execution. rescue handles a matching exception so your program can respond. Prefer a specific exception class when you know which failure you can recover from.

ensure runs when leaving its protected block during normal Ruby control flow, including exception propagation. It is useful for cleanup. Browser termination or stopping the Worker is outside this guarantee.

Example output
Please use digits
Attempt finished
score must be positive

Experiment

Replace "not a number" with "42". Which message disappears?

Check your understanding

Please use digits disappears because conversion succeeds. Attempt finished still prints, and the separate explicit raise is still handled.

A useful tip

A broad rescue can hide programming errors. Handling a failure should have a specific purpose.

Explore the official manual

  • Official Ruby 4.1 development documentation: Exceptions
begin
  Integer("not a number")
rescue ArgumentError
  puts "Please use digits"
ensure
  puts "Attempt finished"
end
begin
  raise ArgumentError, "score must be positive"
rescue ArgumentError => error
  puts error.message
end
