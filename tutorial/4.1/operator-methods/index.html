Operators are methods

Read common operators as methods called on the value to their left.

Development course: behavior may change with future runtime updates.

Learn

Many Ruby operators are methods. The expression 2 + 3 can also be written as 2.+(3): the value on the left is the receiver, and the value on the right is passed to its + method.

The same operator can do different work for different receiver types. Integer + adds numbers, while String + joins text. This lesson uses built-in objects; defining operators for a custom class is a separate topic.

Experiment

  1. Compare two spellings

    Predict both results. Change the argument in the method-call form from 3 to 8; what changes?

  2. Use plus with strings

    What does + do when its receiver is a String? Change the second string to " rules" and predict the output.

  3. Repeat a string

    Predict the output, then change the receiver from "ha" to "go". Which value receives *?

Answers

Compare two spellings

Both forms call + on the Integer 2 with 3, so both print 5. Changing the argument to 8 makes the second result 10.

Use plus with strings

Here + is called on the String "Ruby" and joins the supplied string to it. With " rules", p displays "Ruby rules".

Repeat a string

The String "ha" is the receiver of * and 3 is its argument, so the string repeats three times. With "go", p displays "gogogo".
