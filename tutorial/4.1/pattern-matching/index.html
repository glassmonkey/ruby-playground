Match structured data

Select a branch using the shape and values of a Hash.

Development course: behavior may change with future runtime updates.

Learn

Pattern matching examines a value’s structure. In a case/in expression, a hash pattern can require particular keys and bind values to local variables. This is useful when handling data with several possible shapes.

The role value below must equal "admin". The name: shorthand binds the associated value to name. The else branch handles a mismatch; without a matching branch or else, case/in raises an error.

Example output
Welcome, Ruby

Experiment

Change role to "member" and run again.

Answer

The output is Guest because the literal role requirement no longer matches.

Explore the official manual

  • Official Ruby 4.1 development documentation: Pattern matching
user = { name: "Ruby", role: "admin" }
case user
in { name:, role: "admin" }
  puts "Welcome, #{name}"
else
  puts "Guest"
end
