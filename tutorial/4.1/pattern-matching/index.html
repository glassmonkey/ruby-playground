Match structured data

Select a branch using the shape and values of a Hash.

Development course: behavior may change with future runtime updates.

Learn

Pattern matching examines a value’s structure. In a case/in expression, a hash pattern can require particular keys and bind values to local variables. This is useful when handling data with several possible shapes.

The role value below must equal "admin". The name: shorthand binds the associated value to name. The else branch handles a mismatch; without a matching branch or else, case/in raises an error.

Experiment

  1. Compare matching roles

    Compare this output with Example: why does this data select Guest?

  2. Match a hash shape

    Change count to 5. Which bound value changes?

  3. Choose a matching branch

    Change code to 200. Which branch matches?

Answers

Compare matching roles

The role is member here, so the pattern requiring admin does not match and the else branch prints Guest. Example has role admin and prints Welcome, Ruby.

Match a hash shape

The hash pattern binds count from the matching key, so the printed count becomes 5.

Choose a matching branch

The first hash pattern requires code: 200, so it prints ok.

user = { name: "Ruby", role: "admin" }
case user
in { name:, role: "admin" }
  puts "Welcome, #{name}"
else
  puts "Guest"
end
