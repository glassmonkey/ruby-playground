Ruby Tutorial

Learn the language step by step, then change the code and see what happens.

These 15 lessons build from printing your first value to reading advanced syntax. Each includes an explanation, runnable code, expected output and a practice task with feedback. No installation or account is needed.

Start learning Ruby

Already know some Ruby? Pick a lesson below. Keep the lesson open while you experiment in a separate playground tab.

Core APIs and standard libraries

Array, Hash, Enumerable and Proc appear where they support a language concept. Their full APIs are outside this first path. Standard libraries, gems, Rails, files, network access and interactive standard input are not taught here. Browser runtime limits make some of these unsuitable for this playground.

Versions and verification

Runnable examples target the bundled Ruby 4.0 runtime. You can switch versions in the playground to experiment, but the lessons do not promise identical results across every version. Each run starts fresh. Do not enter secrets: shared URLs contain the full source.
