Your first Ruby program

Print a result and distinguish output from a return value.

Before you start: no previous Ruby experience needed. Examples use bundled Ruby 4.0.

Understand the idea

A Ruby program evaluates expressions in order. In this playground, editing the code starts a new run. The Output panel shows what the program prints; it does not automatically show the value of every expression as an interactive Ruby console would.

Use puts for a readable line of text and p when you want to inspect a value. Text after # is a comment. Indentation makes nested code easier to read; ordinary statements can start on separate lines.

Read, predict, then run

Predict what this program will print before opening it in the playground.

# Print a greeting, then inspect a number.
puts "Hello, Ruby!"
p 2 + 3
p puts("One more line")
Run this lesson in Playground ↗

Opens a new tab so you can keep this lesson open. Code runs automatically; use puts or p to see a result.

Expected output

Hello, Ruby!
5
One more line
nil

Try it yourself

Change 2 + 3 to 2 * 3. Why does the final line still say nil?

Check your understanding

The number becomes 6. puts prints its argument but returns nil; the outer p prints that return value.

Watch out for

Writing 2 + 3 alone produces no visible output here. Wrap it in p.
