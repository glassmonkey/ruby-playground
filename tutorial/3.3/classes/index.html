Create objects with classes

Initialize instance state and expose behavior through methods.

Learn

A class defines behavior for its instances. new creates an instance and calls initialize. Instance variables belong to an object, so separate instances can hold different values.

attr_reader defines a reader method. Public methods form the callable interface; private methods support its implementation. Inheritance lets a subclass reuse and specialize behavior, and super invokes the corresponding superclass implementation.

Example output
1
10

Experiment

Call first.increment twice more. Does second.value change?

Answer

first.value becomes 3. second.value stays 10 because the objects have separate instance variables.

Explore the official manual

  • Official Ruby 3.3 documentation: Modules and Classes
class Counter
  attr_reader :value
  def initialize(start = 0)
    @value = start
  end
  def increment
    @value += 1
  end
end
first = Counter.new
second = Counter.new(10)
first.increment
p first.value
p second.value
