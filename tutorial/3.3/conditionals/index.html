Lesson 4 of 16 · Ruby 3.3

Choose a branch with if and case

Use conditional expressions and recognize Ruby truthiness.

Learn

if selects a branch using a condition. Only false and nil are falsey in Ruby: zero and an empty string are truthy. An if expression also produces the value of its selected branch.

Use elsif to test another condition and else for the fallback. unless runs its branch when a condition is falsey. A case/when expression compares a value against alternatives; ranges can represent groups of numbers.

Experiment

  1. Compare the selected branches

    Compare this run with Example: which case message changes when score is 95?

  2. Use an if result

    Set temperature to -2. Which branch supplies message?

  3. Test Ruby truthiness

    The supplied code tests nil. Change nil to 0: which branch runs now?

Answers

Compare the selected branches

The if message stays pass. The case message changes from on track to excellent because 95 matches the first range.

Use an if result

The condition is true, so the if expression evaluates to "freezing".

Test Ruby truthiness

The original nil takes the else branch and prints skips. With 0, the first branch prints runs: only nil and false are falsey in Ruby.

score = 72
label = if score >= 60
  "pass"
else
  "retry"
end
puts label
puts "zero is truthy" if 0
case score
when 90..100
  puts "excellent"
when 60...90
  puts "on track"
else
  puts "practice"
end
