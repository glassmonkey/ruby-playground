Yield to blocks and store callable behavior

Pass behavior to a method and call a Proc or lambda.

Ruby 3.3 does not support the implicit it block parameter. This lesson uses an explicit |number| parameter instead.

Learn

A block is behavior supplied alongside a method call. A method can invoke it with yield. Block parameters receive the values passed by yield. Blocks can use local variables from their surrounding scope.

A Proc or lambda makes callable behavior available as an object. Invoke it with call. Lambdas enforce argument counts more like methods; Proc and lambda also differ in how return behaves. This example stays with simple expression bodies.

This version uses an explicit block parameter, |number|. The implicit it parameter was introduced in Ruby 3.4 and is not available in this version. Keep the parameter declaration when running this example.

Example output
6
8
12
[2, 4, 6]

Experiment

Change yield 2 to yield 5. Which output changes?

Answer

Only the first result changes, to 15. The two stored callables still receive 4 independently.

def twice
  yield 2
end
p twice { |n| n * 3 }
double = Proc.new { |n| n * 2 }
triple = ->(n) { n * 3 }
p double.call(4)
p triple.call(4)
p [1, 2, 3].map { |number| number * 2 }
