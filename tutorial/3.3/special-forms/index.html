Recognize alias, undef, BEGIN and END

Identify less common forms and their effect on execution.

Learn

alias introduces another name for an existing method at that point in the program. undef makes a method unavailable through that class. These forms affect an interface, so ordinary method definitions are often clearer when no aliasing is needed.

BEGIN executes before the main body and END registers work for normal Ruby process exit. In this playground, the host evaluates the code and then terminates its Worker without a normal Ruby process shutdown. The END block below therefore does not print finish here; running the same program with a local ruby command does print it. The expected output documents the browser behavior.

Example output
start
hello
false

Experiment

Remove undef text. What changes?

Answer

respond_to?(:text) becomes true. Both names are available; the printed greeting remains hello.

Explore the official manual

  • Official Ruby 3.3 documentation: Miscellaneous
BEGIN { puts "start" }
class Message
  def text
    "hello"
  end
  alias original_text text
  undef text
end
puts Message.new.original_text
p Message.new.respond_to?(:text)
END { puts "finish" }
