Code layout and line breaks

Separate Ruby expressions clearly and continue an expression across lines.

Learn

Ruby treats a line break as the end of an expression when the expression is complete. A semicolon can separate expressions on one line, though separate lines are usually easier to read. Indentation helps people see structure; it does not replace Ruby's syntax.

Ruby can continue an expression when the current line is incomplete, such as after +. In that case the next line belongs to the same expression. Use parentheses or a clear line break to show how the parts fit together.

Experiment

  1. Separate statements

    Predict the two printed lines. Then put the assignments on separate lines without changing their values.

  2. Continue an expression

    What does total contain? Change the second addend from 3 to 8 and predict the new output.

  3. Use parentheses

    This expression continues inside parentheses. Predict the result, then change 4 to 6. Does putting the grouped sum on separate lines change the calculation?

Answers

Separate statements

The semicolon separates the two assignments, so Ruby prints 2 and then 3. Moving each assignment to its own line keeps the same output and is easier to scan.

Continue an expression

The plus sign leaves the expression incomplete, so the next line supplies its right-hand value. Changing 3 to 8 makes the output 18.

Use parentheses

The open parenthesis lets the grouped expression continue across lines. The result is 18; changing 4 to 6 makes it 24. Line breaks inside this grouping do not change the arithmetic.
