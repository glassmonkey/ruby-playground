Comments

Add notes to Ruby code with comments that Ruby does not execute.

Learn

A comment begins with # and continues to the end of that line. You can put it on its own line or after Ruby code. Ruby ignores the comment text, so it does not change the program's output.

Use comments to explain a reason or intention that the code does not make clear. Keep executable Ruby outside the comment so the interpreter can run it.

Experiment

  1. Comment out a line

    Predict the output. Then remove the # before the first puts and predict both lines.

  2. Add an end-of-line note

    What prints before the #? Change the number to 9 and predict the result.

  3. Keep code outside the comment

    Predict the output, then change "Ready" to "Done". Which text is part of the comment?

Answers

Comment out a line

Ruby ignores the first line because it starts with #. Removing that # makes the first puts run too, so both lines print.

Add an end-of-line note

The text after # is a comment, so puts prints the assigned value 4. Changing the number to 9 makes it print 9.

Keep code outside the comment

Ruby runs puts and ignores the note after #. Changing the string changes the output to Done; the words after # still have no effect.
