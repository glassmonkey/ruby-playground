Choose a branch with if and case

Use conditional expressions and recognize Ruby truthiness.

Run it first

Run the example and see what it prints. Each run starts fresh.

Expected output of the original example (Ruby 3.2)
pass
zero is truthy
on track

How it works

if selects a branch using a condition. Only false and nil are falsey in Ruby: zero and an empty string are truthy. An if expression also produces the value of its selected branch.

Use elsif to test another condition and else for the fallback. unless runs its branch when a condition is falsey. A case/when expression compares a value against alternatives; ranges can represent groups of numbers.

Try it yourself

Change score to 95 and predict both score-related messages.

Check your understanding

The messages are pass and excellent. The condition still passes, but case now selects the first range.

Watch out for

An empty collection is also truthy. Test empty? when you mean “contains no elements”.

score = 72
label = if score >= 60
  "pass"
else
  "retry"
end
puts label
puts "zero is truthy" if 0
case score
when 90..100
  puts "excellent"
when 60...90
  puts "on track"
else
  puts "practice"
end
