Lesson 2 of 16 · Ruby 4.0

Numbers, strings and symbols

Recognize literal values and interpolate a value into a string.

Learn

A literal writes a value directly in your program. 7 is an Integer and 7.0 is a Float. Double-quoted strings can insert the result of an expression with #{...}. Single-quoted strings do not perform that interpolation.

A Symbol, such as :ruby, is often used as a name or key. true and false represent boolean values; nil commonly represents an absent value. These are objects too, and you can ask each object for its class.

Experiment

  1. Compare division results

    This version divides 7 by a Float. Compare it with Example: what result changes, and why?

  2. Interpolate a value

    Change the language value to "Ruby 4". What part of the sentence changes?

  3. Compare literal types

    Which values have different classes, and are the symbol and string equal?

Answers

Compare division results

The division result changes from 3 to 3.5. With a Float operand Ruby performs floating-point division; the Example uses two Integers.

Interpolate a value

Interpolation inserts the current value of language into the double-quoted string.

Compare literal types

7 is an Integer, 7.0 is a Float, and :ruby is a Symbol distinct from the String "ruby".
