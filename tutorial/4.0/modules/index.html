Share behavior with modules

Include instance behavior and organize names with a module.

Learn

A module can group related names and define methods for reuse. include makes a module’s instance methods available to instances of the including class. You cannot instantiate a module with new.

Modules also provide namespaces. Qualify a nested constant with :: to identify where it belongs. include, extend and prepend serve different purposes; this lesson demonstrates include only.

Example output
item: book

Experiment

Change Product#name to return "pen".

Answer

The output becomes item: pen. The included method calls name on the same Product instance.

Explore the official manual

  • Official Ruby 4.0 documentation: Modules and Classes
module Named
  def label
    "item: #{name}"
  end
end
class Product
  include Named
  def name
    "book"
  end
end
puts Product.new.label
