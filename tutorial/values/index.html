Numbers, strings and symbols

Recognize literal values and interpolate a value into a string.

Before you start: Your first Ruby program. Examples use bundled Ruby 4.0.

Understand the idea

A literal writes a value directly in your program. 7 is an Integer and 7.0 is a Float. Double-quoted strings can insert the result of an expression with #{...}. Single-quoted strings do not perform that interpolation.

A Symbol, such as :ruby, is often used as a name or key. true and false represent boolean values; nil commonly represents an absent value. These are objects too, and you can ask each object for its class.

Read, predict, then run

Predict what this program will print before opening it in the playground.

language = "Ruby"
puts "Hello, #{language}!"
p 7 / 2
p 7.0 / 2
p :ruby.class
p nil.nil?

Try it yourself

Change 7 / 2 to 7 / 2.0. Predict the result before running.

Check your understanding

The result is 3.5 because one operand is a Float. Integer division in the original expression returned 3.

Watch out for

A Symbol and a String with similar spelling are different values: :ruby == "ruby" is false.
