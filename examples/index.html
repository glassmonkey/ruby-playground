Print values with puts and p

puts prints a readable message; p shows the representation of an array. 

puts "Hello, Ruby!"
p [1, 2, 3]

Expected output

Hello, Ruby!
[1, 2, 3]

Change the message and add another element to the array.

Transform arrays with map, select and reduce

map transforms each element, select keeps matching elements, and reduce combines them. 

numbers = [1, 2, 3, 4]
p numbers.map { |n| n * 2 }
p numbers.select { |n| n.even? }
p numbers.reduce(0) { |sum, n| sum + n }

Expected output

[2, 4, 6, 8]
[2, 4]
10

Replace even? with odd? and compare the selected values.

Read and transform a Hash

fetch reads a value by key. transform_values builds a new hash with changed values. 

scores = { ruby: 10, python: 8 }
p scores.fetch(:ruby)
p scores.transform_values { |score| score * 2 }

Expected output

10
{ruby: 20, python: 16}

Try fetching a missing key with a default: scores.fetch(:go, 0).

Use blocks, Procs and lambdas

A block supplies behavior to a method. A Proc or lambda stores callable behavior in a variable. 

3.times { |i| puts i }
double = Proc.new { |n| n * 2 }
triple = ->(n) { n * 3 }
p double.call(4)
p triple.call(4)

Expected output

0
1
2
8
12

Change the arguments passed to call and predict the results.

Match a Hash with a Ruby pattern

Pattern matching checks the shape of a value and binds matching parts to local variables. 

user = { name: "Ruby", role: "admin" }
case user
in { name:, role: "admin" }
  puts "Welcome, #{name}"
else
  puts "Guest"
end

Expected output

Welcome, Ruby

Change the role to member to try the else branch.
