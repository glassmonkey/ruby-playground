Security

Code executes in your browser. Running unfamiliar code can still affect your browser or device, so only use code and shared links from sources you trust.

Shared links run automatically when opened, and anyone with the URL can read the code. Keep passwords, personal information, and other confidential data out of your examples.

A shared link may include a Gemfile. Opening it can download and run third-party Ruby gems along with the shared program. Use only links and gems from sources you trust. The gem proxy receives your IP address and the names and files of requested gems. Downloaded packages stay in your browser's Cache Storage until you clear site data or your browser removes them.
