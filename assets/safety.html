安全な利用

Ruby Playground はコードをブラウザ内の Ruby WebAssembly 実行環境で動かします。 Ruby から JavaScript のホスト機能へアクセスする bridge は無効です。

実行ごとに新しい Worker と VM を使い、実行は 20 秒、出力は合計 100 KB、コードは 50,000 文字までです。停止操作で Worker を終了します。これらの制限は完全な CPU やメモリー隔離を保証するものではありません。

共有 URL にはコードが含まれます。秘密情報や個人情報を入力・共有しないでください。 コード・バージョンはアドレスバーの URL に自動保存されます。URL をコピーして共有できます。 コードを実行できても、URL の長さによって保存できない場合があります。その場合は警告を表示し、古いコードの URL を残さず、エディターの内容は保持します。 共有リンクを開いた際や編集・バージョン変更後に自動実行します。信頼できない共有リンクを開かないでください。配布 WASM の Ruby 4.0.0 / 3.4.1 / 3.3.3 は最新のセキュリティ修正版ではありません。 低速回線では初回の Ruby 読み込みがタイムアウトすることがあります。通信環境を変え、コードを編集するかバージョンを変更してください。
