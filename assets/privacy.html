このアプリにアクセス解析やテレメトリーは追加していません。Ruby の実行はブラウザ内で行い、 実行結果をアプリのサーバーへ保存する機能はありません。

共有 URL のクエリには Ruby コードが含まれます。ブラウザーの履歴、コピー先、受信者、 ブラウザー同期、ホスティング基盤のリクエスト処理などに URL が残る可能性があります。 GitHub Pages はセキュリティ目的で訪問者の IP アドレスを記録・保存すると説明しています。 クエリ文字列の保持期間はこのアプリでは確認できません。秘密情報を共有 URL に入れないでください。

ページの referrer policy は no-referrer です。これはリンク遷移時の通常の referrer 送信を抑える設定であり、URL 自体の履歴やホスティング基盤の処理を消すものではありません。
