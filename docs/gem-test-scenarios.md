# Gem support test scenarios

This inventory separates mocked unit tests, checks against a local Worker, and
browser flows. A browser flow may also exercise the local Worker; it is listed
once as a browser scenario, with the HTTP path noted as secondary evidence.
WASM tests that inject a `GemSource` are component tests, not local proxy
integration tests.

“Existing” and “New” identify scenario behavior relative to the WIP baseline
commit `0052da0`; they do not imply that the current test file was already in
that commit. The historical browser section records prior, uncommitted
real-upstream test versions and does not establish results for the current
VCR-backed specs.

Statuses distinguish current local results from historical evidence. Current
unique automated checks total 169: 149 focused app/proxy tests (139 unit and
10 Ruby WASM component), three cassette-integrity tests, nine local Worker API
checks, and eight browser scenarios. The Worker requests inside browser tests
are secondary evidence and are not counted twice. Earlier 106- and 19-test
reports are subsets of the 149; the historical synthetic browser 8/8 and six
live-upstream browser scenarios are not additive. Typecheck, lint, additional
ESLint checks, and build passed; build emitted only the known chunk-size
warning. No CI dispatch, credentialed deployment, or public endpoint run was
performed. The production-config Wrangler dry run is historical and does not
verify the VCR fixture or public service.
A portable equivalent for the focused test run is:

```sh
npx vitest run src/__test__/gems.test.ts src/__test__/share.test.ts src/__test__/gem-proxy.test.ts src/workers/__test__/client.test.ts proxy/src --reporter=default
```

## VCR-backed browser integration

Normal browser and proxy API tests replay recorded RubyGems HTTP responses over
local HTTP. They have no external fallback. Only an explicitly authorized
recording operation contacts the public primary source. The three confirmed
recorded packages are `rainbow` 3.1.1, `pastel` 0.8.0, and `tty-color` 0.6.0;
metadata and recorded gem checksums agree. The replay bodies total about 46 KB. Each archive includes an MIT license.
The recording manifest is [`proxy/test-fixtures/cassettes/manifest.json`](../proxy/test-fixtures/cassettes/manifest.json), recorded at `2026-11-01T09:36:44Z`. It lists upstream source URLs, status, selected headers, response body file, byte count and SHA-256. Header names are lowercased and values trimmed; volatile request IDs and host IDs are excluded from captured headers. The captured missing-package XML response substitutes fixed placeholder values for `RequestId` and `HostId`; its manifest includes both raw and normalized body hashes. The archive request for `rainbow-0.0.1.gem` returned HTTP 403, while the separately recorded missing-info response returned HTTP 404. These are distinct response inputs, not an additional browser scenario. The explicit recorder is `RUBYGEMS_CASSETTE_RECORD=1 npm --prefix proxy run record:fixtures`; routine tests replay local cassettes and do not fall back to RubyGems.

The VCR browser suite passed 8/8 in 34.7 seconds against Vite preview with local Wrangler and cassette replay. Browser requests to the public RubyGems origin were blocked and none were observed. Playwright stopped its own servers; ports 8787 and 18787 were free afterward. The first functional run installed Rainbow but its default ANSI-colored output did not match the test's plain-text expectation. The test program now sets `Rainbow.enabled = false`; this corrected the test input and required no app runtime change.
